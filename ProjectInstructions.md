These are the instructions for the project:
The purpose of this project is to create a hobby web application for Old School RuneScape game which will be used to help traders make decisions.

Use easy decisions for a hobby project tech stack and prefer free and open source solutions.

The application will have the following features:
- A tool to help traders make decisions.
- The website should have listing of all items which can be filtered and sorted by buy price, sell price, margin, volume, price change, margin*volume etc.
- The website should have a search bar to search for items by name.
- users should be able to favorite items and have a list of favorite items.
- users should be able to add items to discord market watch list.
- users should be able to opt in to receive notifications in discord for market highlights.
- integration for a discord bot which will be used to send notifications to traders.
- discord bot can send price updates for selected items.
- discord bot can send AI assisted highlights from the market.
- website should calculate commonly used market values for items and include common trading tools and market analysis.
- include item icons from osrs wiki to help identify items.
- Use AI to find interesting items to trade and send notifications to traders and website.
- the website should be responsive and mobile friendly.
- the website should be secure and have a proper login system.
- the website should be easy to use and navigate.
- the website should be fast and efficient.
- the website should be scalable and easy to maintain.
- Do not expose API keys or secrets in repository.
- Include readme file with instructions on how to run the project.
